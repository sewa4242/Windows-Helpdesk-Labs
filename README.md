# Windows Helpdesk Labs

Repozytorium dokumentuje moje praktyczne ćwiczenia związane
z administracją oraz diagnostyką systemów Windows 10/11.

Celem laboratoriów jest przygotowanie do pracy na stanowisku
Helpdesk / IT Support I/II linii.

## Zakres

- diagnostyka sieci TCP/IP
- DNS i DHCP
- konfiguracja Windows 10/11
- troubleshooting
- drukarki
- konta użytkowników
- Microsoft 365
- scenariusze zgłoszeń Helpdesk
